# 🚌 PravasApplication

PravasApplication is an Android-based bus ticket booking application developed using Java. The application helps users book bus tickets efficiently with features like fare calculation, ticket management, and real-time validation.

The project focuses on providing a smooth and user-friendly ticket booking experience while implementing backend logic and database management.

---

## 🚀 Features

- Bus Ticket Booking
- Fare Calculation
- Ticket Management
- Seat Availability Handling
- CRUD Operations
- Real-time Input Validation
- User-friendly Interface
- Database Integration

## ▶️ How to Run the Project

### Clone Repository

```bash
git clone https://github.com/18anki/PravasApplication.git
```

### Open Project

- Open Android Studio
- Select `Open Existing Project`
- Choose the cloned repository folder

### Build & Run

- Sync Gradle files
- Run the application on Emulator or Android Device
